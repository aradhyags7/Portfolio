## 🌌 Overview

This repository hosts the source code for **Aradhya Shinde**'s personal portfolio. Engineered with pure HTML5, vanilla CSS, and modern ESNext JavaScript, it delivers 60fps animations, instant load times, and an immersive user experience without heavy framework overhead.

### Key Highlights
- ⚡ **Interactive Constellation Canvas**: Physics-driven HTML5 canvas calculating real-time inter-particle distance and mouse-attraction line bridging at 60 FPS.
- 🎨 **Minimalist Charcoal & Crimson Design System**: Deep `#1a1a1a` canvas accented with `#ff4d5a` crimson highlights and signature 70px heading bars.
- 💻 **Realistic macOS Code Mockup Terminals**: Custom IDE window headers with realistic syntax-highlighted code snippets and live benchmark badges.
- 📱 **Interactive Project Modals**: Dynamic case-study popups with zero external libraries, featuring test coverage statistics, latency benchmarks, and direct GitHub source navigation.
- 🧭 **Intelligent Navigation**: Sticky navigation bar with frosted-glass backdrop blur and real-time active section tracking.

## 🛠️ Tech Stack & Architecture

- **Core**: Vanilla HTML5, ESNext JavaScript, Vanilla CSS
- **Styling**: BEM methodology, CSS Custom Properties (Design Tokens), Glassmorphism, CSS Grid & Flexbox
- **Physics**: HTML5 `<canvas>` 2D particle simulation
- **Build Tool**: [Vite](https://vitejs.dev/) for blazing fast development and optimized asset bundling
- **Typography**: `Raleway` (Headings) & `Montserrat` (Body) via Google Fonts

## 🏃 Getting Started Locally

### Prerequisites
- Node.js (v18.0 or later)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/aradhyags7/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dev dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
# Compile and bundle assets for production
npm run build

# Preview production build locally
npm run preview
```
